# 一、项目概要

**绒球是一个个人决策校准系统。**

用户带着一个正在犹豫的问题进来，系统把它拆成结构：

- **N 个事实面**（支持 / 反对，严格二元）
- **1 个半知**（隐约知道但未验证的东西）
- **1 个未知**（明确不知道自己不知道的）

然后给出一个**参考倾向 + 置信度**，并记录归档；到期回收结果，形成用户本人的校准曲线。

**它不预测未来，不给建议，不替用户做决定。**

# 二、问题陈述

## 2.1 我们原来在做什么

项目前身是一个量化交易系统（quant-lab），做过七套策略，最终全部被否决：

| 结论 | 数据 |
|---|---|
| 成本吞掉一切 | 双边成本 14bps，最好的边际 0.95bps |
| 分散化是乘数不是加数 | 无法替代正期望 |
| 样本外表现 | Sharpe 0.05 vs BTC 0.76 |

**结论：在完全竞争的市场里，个人无法靠信息优势取胜。**

## 2.2 真正的缺口

**市场上所有的信息产品，都在解决「你不知道什么」。**
**没有一个在解决「你不知道自己不知道什么」。**

具体表现：

1. **信息过剩，判断力稀缺。** 一个人可以做十次搜索，却仍然不知道自己在犹豫什么。
2. **AI 替代判断。** 主流 AI 给答案，用户逐渐失去自己做判断的能力。
3. **他人的观点被当成证据。** 舆论、统计、专家意见被大量当作事实使用。
4. **没有校准。** 没有任何工具记录「你说过的判断，后来对不对」。
5. **过度自信是系统性的。** 人工智能越是自信地给答案，这个问题越严重。

## 2.3 目标用户

| 阶段 | 用户 | 场景 |
|---|---|---|
| 第一阶段 | 个人用户 | 日常犹豫：去不去、要不要、说不说 |
| 第二阶段 | 管理者 / 创业者 | 高价值决策：招人、投入、放弃 |
| 第三阶段 | 组织 | 决策复盘、组织校准 |
| 第四阶段 | 教育 | 青少年决策习惯养成 |

# 三、核心主张

> **判断一个事物的方向，要找到与它直接接触的实体，然后判断那个实体。**

这句话是全部设计的地基。它推出四个可执行的原则：

## 3.1 第一接触面 = 马尔可夫毯

**只找直接因、直接果、共同原因。**

给定马尔可夫毯，该节点与其余世界条件独立。**所以只看直接接触的面，就足以判断——不多也不少。**

这就解释了为什么「链长 ≤ 3」：越过两跳的信息，是别人对世界的判断，不是世界对这个节点的直接作用。

## 3.2 他人观点零权重

**别人的看法不是外部力量，是回声。**

信息瀑和回音室摧毁独立性，相关意见不携带新信息。**聚合只会放大误差。**

## 3.3 8020 不是估的，是封顶的

```
可确定 = min(N / (N + 2), 0.8) × 0.8^(链长 - 1)
剩余 20% 对半分：10% 半知 + 10% 未知
```

**N 再多也超不过 80%。**

理论依据两条：
- **毛球定理**：一定有盲区（拓扑必然）
- **必要多样性定律**：世界无限、视野有限（信息论必然）

## 3.4 事实二元，中性只属于 11

**事实层只有支持 / 反对。**
**中性只存在于半知和未知两个槽里。**

不作弃权——因为不决定本身就是一种决定。

# 四、产品定义

## 4.1 它是什么

| | |
|---|---|
| 输入 | 一句自然语言的犹豫 |
| 处理 | 拆主谓宾 → 找第一接触面 → 判定方向 → 计数 |
| 输出 | 一个结构 + 一个倾向 + 一个置信度 |
| 沉淀 | 判断归档 → 到期回收 → 个人校准曲线 |

## 4.2 它不是什么

- ❌ 不是搜索引擎
- ❌ 不是一个给答案的 AI
- ❌ 不是算命、不是人生规划
- ❌ 不是心理咨询
- ❌ 不是决策自动化工具

## 4.3 核心交互原则

| 原则 | 实现 |
|---|---|
| 能用点就不打字 | 固定询问面：是 / 否 两键 |
| 结论优先 | 结论占一屏最显眼位置，明细默认收起 |
| 不引导 | 只给结构，不给方向建议 |
| 可追溯 | 依据全公开，任何结论都能查 |
| 少即是多 | 一屏只显示必要的三样东西 |

# 六、潜藏能力（框架里已有、尚未使用的）

**下面这六种能力，不是新设计。**

**它们是从现有公理往回推出来的——结构里本来就有，只是我们一次都没用过。**

推导的起点只有一句：

> **绒球不只有「一次判断」，它有「判断的结构」。**
>
> **而结构可以比对、可以叠加、可以排序、可以纵向看。**

**主流软件只有「内容」，所以只能做推荐。**
**绒球有「结构」，所以能做的事是另一个维度。**

---

## 6.1 跨决定的共同根因 —— 五件事其实是同一件事

### 框架为什么支持

**每条事实都有「方向」，而方向是相对于某个二元的。**

```
「老张邀请了我」
  →  支持「去聚餐」
  →  反对「今晚早睡」
  →  支持「见老同学」
  →  反对「省钱」
```

> **同一个事实，对不同的决定有不同的方向。**

**所以可以反过来建索引：事实 → 它影响的所有决定。**

### 它回答什么

> **「你这周在纠结的 5 件事，其实有 3 件是同一个根。」**

**人以为自己有五个问题，其实常常只有一个。**

### 实现要点

- 建立「事实 → 决定」的反向索引
- 用事实的主谓宾做归一化匹配
- 输出：一组共享第一接触面的决定，以及那个共同的面

**这是「结构」这个设计最没被用掉的一次幂。**

---

## 6.2 决策的拓扑排序 —— 哪个决定在最上游

### 框架为什么支持

**每个决定都有第一接触面，而有些接触面本身就是另一个决定。**

```
换工作  ←  第一接触面：要不要搬家
搬家    ←  第一接触面：要不要和伴侣异地
异地    ←  第一接触面：伴侣愿不愿意
```

> **决定之间有依赖关系，而依赖关系是可以画的。**

### 它回答什么

> **「你正在做的这些决定，上游是那个。」**
> **「先做上游那个，下游的会自动简化。」**

**大多数人卡住，不是因为选不出，是因为在同时解五个方程。**

### 实现要点

- 检测一个决定的接触面是否命中另一个待决定义
- 建立有向依赖图，检测环
- 输出拓扑序，标出根决定

---

## 6.3 框架效应检测 —— 换个说法，答案还一样吗

### 框架为什么支持

**绒球的输入是自然语言，而自然语言的表述方式会改变判断。**

```
「我有 70% 机会成功」   vs   「我有 30% 机会失败」
——同一个事实，人的选择常常不一样。
```

### 它回答什么

**同一件事，换三种说法各判一次：**

| 结果 | 说明 |
|---|---|
| 三次一致 | **你的判断是稳的** |
| 三次不一致 | **你被表述方式左右了** |

> **「同一件事，你换了说法就换了答案——说明你还没想清楚。」**

**这不是批评，是诊断。**

### 实现要点

- 生成同一决定的 2–3 种等价表述
- 分别走完整判断流程
- 比较结论方向与置信度
- 输出一致性分数

**注意：这是「测用户」，不是「教用户」。不得提示哪种说法才是对的。**

---

## 6.4 判断漂移 —— 一周后再判，什么变了

### 框架为什么支持

**每条判断都带时间戳、置信度、N、链长。**

**所以可以做纵向对比：**

```
3 月 1 日：  支持 2 / 反对 3   可确定 61%
3 月 8 日：  支持 4 / 反对 3   可确定 70%
```

### 它回答什么

> **「这两个星期，是事实变了，还是你变了？」**

**如果是事实变了 → 你该更新判断。**
**如果是你变了、事实没变 → 那是情绪在替你判。**

### 实现要点

- 用主谓宾 + 原核做同一决定的识别
- 比较两次的事实集合差异（新增 / 消失 / 翻转）
- 把差异分成「事实变化」和「判断变化」两类

**——这是「漂移」和「成长」的区别，而以前没人分得清。**

---

## 6.5 沉默的面 —— 你说出 3 个，这类决定通常有 7 个

### 框架为什么支持

**811 里 N 是可数的，而 N 有一个「期望值」。**

**同一个类型的决定，大量用户的第一接触面数量会收敛到一个区间。**

### 它回答什么

> **「你说出来的面有 3 个。这类决定，通常有 6–8 个。」**

**它不说你漏了哪几个（那是引导），只说「你的面数偏少」。**

### 实现要点

- 按决策类型统计 N 的分布（中位数 + 分位区间）
- 只输出「偏少 / 正常 / 偏多」，不输出缺哪几个
- 隐私要求：只能用聚合分位数，不能反推个体

**——这是「N 是发现的」这句话的反面用法：**
**不只发现你的 N，还能发现「你的 N 够不够」。**

---

## 6.6 校准缺口预警 —— 你的数字比你的历史高

### 框架为什么支持

**它有你的历史：你在这类决定上说过多少次 80%，实际命中多少。**

### 它回答什么

> **「这次你说 85%。但你在这一类上，历史命中是 61%。」**

**——这不是建议，是把你的历史摆在你面前。**

### 实现要点

- 按决策类型维护个人校准曲线
- 当前置信度 vs 该类历史命中率 → 缺口
- 缺口超过阈值才提示，且只陈述数字

**这是唯一一种「用数据帮你」又不算引导的方式：**
**因为它说的是「你以前是什么样」，不是「你这次该怎样」。**

---

# 七、这六个能力的共同点

**它们全部来自同一件事：**

> **绒球真正的能力不是「帮用户判断什么」，是「让判断本身变得可观察」。**

```
一次判断           →  答案
一百次判断         →  画像
一百次判断的结构    →  一个人的思维解剖图
```

**那才是它最后会长成的东西。**

**当前 11 只是两个被展示的槽，没有参与任何计算。**

要做的是从两个槽里算出「**这个判断有多稳**」：

1. **翻转阈值** —— 距离结论翻转还差几条事实（纯计算）
2. **最脆弱的假设** —— 来自半知槽，整个判断建立在这条之上
3. **还缺什么** —— 来自未知槽 + 按类别的缺口清单

**关键：输出的是元信息，不是建议。**
> ❌「建议你去」 ✅「只差 1 条事实就会翻转」

| 1 | **镜子变神谕** | 致命 | 界面永不输出建议；文案保留「判断是趋近值」 |

| 5 | **无差异化护城河** | 中 | 时间积累的校准基准 + 问句库 + 信任 |
| 6 | **无法变现** | 中 | B 端养 C 端；日活层永远不赚钱 |
| 7 | **大厂复制** | 中 | 他们的商业模式不允许他们放弃引导 |

# 十三、结论

**绒球要解决的不是「信息不够」，是「判断不清」。**

**它不生产答案，它生产清晰。**

**而第六章的六个潜藏能力说明了一件事：**

> **它真正的能力，不是「帮用户判断什么」。**
> **是「让判断本身变得可观察」。**

```
一次判断            →  答案
一百次判断          →  画像
一百次判断的结构     →  一个人的思维解剖图
```

**那才是它最后会长成的东西。**
