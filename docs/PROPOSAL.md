# 一、项目概要

**绒球是一个个人决策校准系统。**

用户带着一个正在犹豫的问题进来，系统把它拆成结构：

- **N 个事实面**（支持 / 反对，严格二元）
- **1 个半知**（隐约知道但未验证的东西）
- **1 个未知**（明确不知道自己不知道的）

然后给出一个**参考倾向 + 置信度**，并记录归档；到期回收结果，形成用户本人的校准曲线。

**它不预测未来，不给建议，不替用户做决定。**

# 二、问题陈述

## 2.1 我们原来在做什么

项目前身是一个量化交易系统（quant-lab），做过七套策略，最终全部被否决：

| 结论 | 数据 |
|---|---|
| 成本吞掉一切 | 双边成本 14bps，最好的边际 0.95bps |
| 分散化是乘数不是加数 | 无法替代正期望 |
| 样本外表现 | Sharpe 0.05 vs BTC 0.76 |

**结论：在完全竞争的市场里，个人无法靠信息优势取胜。**

## 2.2 真正的缺口

**市场上所有的信息产品，都在解决「你不知道什么」。**
**没有一个在解决「你不知道自己不知道什么」。**

具体表现：

1. **信息过剩，判断力稀缺。** 一个人可以做十次搜索，却仍然不知道自己在犹豫什么。
2. **AI 替代判断。** 主流 AI 给答案，用户逐渐失去自己做判断的能力。
3. **他人的观点被当成证据。** 舆论、统计、专家意见被大量当作事实使用。
4. **没有校准。** 没有任何工具记录「你说过的判断，后来对不对」。
5. **过度自信是系统性的。** 人工智能越是自信地给答案，这个问题越严重。

## 2.3 目标用户

| 阶段 | 用户 | 场景 |
|---|---|---|
| 第一阶段 | 个人用户 | 日常犹豫：去不去、要不要、说不说 |
| 第二阶段 | 管理者 / 创业者 | 高价值决策：招人、投入、放弃 |
| 第三阶段 | 组织 | 决策复盘、组织校准 |
| 第四阶段 | 教育 | 青少年决策习惯养成 |

# 三、核心主张

> **判断一个事物的方向，要找到与它直接接触的实体，然后判断那个实体。**

这句话是全部设计的地基。它推出四个可执行的原则：

## 3.1 第一接触面 = 马尔可夫毯

**只找直接因、直接果、共同原因。**

给定马尔可夫毯，该节点与其余世界条件独立。**所以只看直接接触的面，就足以判断——不多也不少。**

这就解释了为什么「链长 ≤ 3」：越过两跳的信息，是别人对世界的判断，不是世界对这个节点的直接作用。

## 3.2 他人观点零权重

**别人的看法不是外部力量，是回声。**

信息瀑和回音室摧毁独立性，相关意见不携带新信息。**聚合只会放大误差。**

## 3.3 8020 不是估的，是封顶的

```
可确定 = min(N / (N + 2), 0.8) × 0.8^(链长 - 1)
剩余 20% 对半分：10% 半知 + 10% 未知
```

**N 再多也超不过 80%。**

理论依据两条：
- **毛球定理**：一定有盲区（拓扑必然）
- **必要多样性定律**：世界无限、视野有限（信息论必然）

## 3.4 事实二元，中性只属于 11

**事实层只有支持 / 反对。**
**中性只存在于半知和未知两个槽里。**

不作弃权——因为不决定本身就是一种决定。

# 四、产品定义

## 4.1 它是什么

| | |
|---|---|
| 输入 | 一句自然语言的犹豫 |
| 处理 | 拆主谓宾 → 找第一接触面 → 判定方向 → 计数 |
| 输出 | 一个结构 + 一个倾向 + 一个置信度 |
| 沉淀 | 判断归档 → 到期回收 → 个人校准曲线 |

## 4.2 它不是什么

- ❌ 不是搜索引擎
- ❌ 不是一个给答案的 AI
- ❌ 不是算命、不是人生规划
- ❌ 不是心理咨询
- ❌ 不是决策自动化工具

## 4.3 核心交互原则

| 原则 | 实现 |
|---|---|
| 能用点就不打字 | 固定询问面：是 / 否 两键 |
| 结论优先 | 结论占一屏最显眼位置，明细默认收起 |
| 不引导 | 只给结构，不给方向建议 |
| 可追溯 | 依据全公开，任何结论都能查 |
| 少即是多 | 一屏只显示必要的三样东西 |

## M1 · 让 11 参与计算（下一步）

**当前 11 只是两个被展示的槽，没有参与任何计算。**

要做的是从两个槽里算出「**这个判断有多稳**」：

1. **翻转阈值** —— 距离结论翻转还差几条事实（纯计算）
2. **最脆弱的假设** —— 来自半知槽，整个判断建立在这条之上
3. **还缺什么** —— 来自未知槽 + 按类别的缺口清单

**关键：输出的是元信息，不是建议。**
> ❌「建议你去」 ✅「只差 1 条事实就会翻转」

# 八、成功指标

## 8.1 绝不使用的指标

- ❌ 日活 / 时长 / 留存
- ❌ 广告收入
- ❌ 用户使用频次

**因为这些指标一旦成为目标，产品就会开始引导用户。**

## 8.2 唯一有效的指标

| 指标 | 定义 |
|---|---|
| **校准改善** | 用户的置信度与命中率之间差距是否收窄 |
| **判断回收率** | 归档的判断中，按期回来报告结果的比例 |
| **结构性使用** | 用户是否从「随便问问」转向「重要决定先过一遍」 |
| **依赖度下降** | 用户是否需要它越来越少（镜子的成功标准） |

# 九、风险

| # | 风险 | 影响 | 应对 |
|---|---|---|---|
| 1 | **镜子变神谕** | 致命 | 界面永不输出建议；文案保留「判断是趋近值」 |
| 2 | **伪精确** | 高 | 置信度是启发式，必须明示；不宣称科学测量 |
| 3 | **数据泄露** | 致命 | 内容不出设备；只上传数字 |
| 4 | **文化偏差** | 高 | 结构普遍，词汇本地化 |
| 5 | **无差异化护城河** | 中 | 时间积累的校准基准 + 问句库 + 信任 |
| 6 | **无法变现** | 中 | B 端养 C 端；日活层永远不赚钱 |
| 7 | **大厂复制** | 中 | 他们的商业模式不允许他们放弃引导 |

# 十、结论

**绒球要解决的不是「信息不够」，是「判断不清」。**

**它不生产答案，它生产清晰。**

**如果这个项目只能留下一句话，那句话是：**

> **「我不告诉你该怎么做。我只让你看清，你正在拿什么做这个决定。」**

**——这句话如果守得住，项目就成立；守不住，代码写得再好也没有意义。**
