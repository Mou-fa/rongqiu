# 危机本地记录（Crisis Record）

> 危机触发时，先把这一刻的第一接触面留在用户自己的设备上。
> 只写本机，不上传、不联网、不进入校准、不参与统计。

---

## 1. 保存什么

输入命中轻生/自伤/绝望标签时，绒球停止判断，并在本机写：

    data/crisis/<event_id>.json
    data/crisis/<event_id>.manifest.json

记录只包含：

- **问题**：用户当时输入的那句话；
- **地区**：用户已授权定位时拿到的地区（没有就是空字符串）；
- **时间**：本地时间、UTC、时区、UTC 偏移；
- **元信息**：事件 ID、schema 版本、来源（ask / judge）、保存说明。

**不保存**：回答、自述、勾选场景、坐标、历史判断、journal 副本。

## 2. 为什么只保留第一接触面

这个设计不是为了少存，是为了不制造误读：

- 家属和警方要知道的是「当时问了什么、什么时候、在哪儿」；
- 完整的历史判断不能证明因果，却很容易被读成「绒球过去的判断引导了轻生」；
- 保存越少，二次泄露和二次伤害的路径越少；
- 只保留第一接触面，已经足够回答最必要的事实。

## 3. 完整性

每个事件有一份 SHA-256 清单：

- 事件 JSON 的哈希；
- 清单本身不包含在哈希里，只描述被保存的文件。

校验命令（Windows）：

    certutil -hashfile <文件名> SHA256

哈希只能证明文件没有被改动，**不能证明内容真实，也不能证明作者身份**。

## 4. 本地导出

家属或警方在取得设备/合法授权后，可以主动导出：

    python scripts/export_crisis.py --list
    python scripts/export_crisis.py --event <event_id> --open

不指定 --out 时，默认导出到：

    C:\Users\<用户>\Documents\RongqiuCrisisExports\<event_id>\

方便在文件管理器里直接找到；--out 可以指定别的位置；--open 导出后直接打开文件夹。

如果系统权限拒绝写 Documents（例如 Windows 受控文件夹访问阻止了 Python），工具会自动退到仓库/当前目录下的 `exports/`；也可以用 --out 指到 U 盘或一个你有写权限的目录。

导出目录包含：

- 原始事件 JSON（问题 / 时间 / 地区）；
- 摘要.txt（给家属/警方直接阅读的一页纸）；
- SHA-256 清单；
- README.txt（说明数据来源、时间、哈希校验方式）；
- SHA256SUMS。

导出工具只读本机 data/crisis/，只写用户指定目录，不联网、不上传。

## 5. 访问边界（重要）

**绒球不会自动把危机记录交给警方、家属或任何第三方。**

原因：

1. 如果用户知道「危机里说的话会自动交给别人」，最需要被接住的人会躲开；
2. 数据离开设备后可能被二次泄露、断章取义或用来指责当事人；
3. 产品无法判断谁有资格看、用户是否已经不在、家属是否善意；
4. 本地设备上的记录，警方依法调取设备即可；产品不建云端副本，反而少一条泄露路径。

因此：

- 默认只有设备持有者能打开；
- 导出必须由设备持有者主动执行；
- 未来如果做「紧急联系人 / 身后可见」，必须是用户生前明确设置、可撤回、走 B2 身份层，不默认开启；
- 不做隐藏后门，不做远程解锁，不做自动上报。

## 6. 删除与迁移

删除整个目录即可：

    data/crisis/

旧版快照曾包含 journal 副本。运行迁移命令：

    python scripts/export_crisis.py --migrate

v2 迁移会自动：

- 删除旧版的 .journal.jsonl；
- 把 request 收敛为问题 / 地区；
- 重建 SHA-256 清单。

迁移不保留历史副本，避免旧快照继续带来误读风险。

## 7. 限制

- 只保存第一接触面，不保存完整决策过程；
- 无法验证记录是否由本人操作；
- 无法验证用户是否处于真实危险，危机判断是保守触发；
- 不是司法鉴定报告，不能替代警方取证；
- 家属/警方使用时应遵守当地法律与最小必要原则。

## 8. 手机端（规划）

手机端不能只是网页壳，记录要真正落在手机本地：

- 手机本地保存第一接触面（问题 / 时间 / 地区），与桌面同一套 schema v2；
- 手机上的「本机记录」列表可离线查看；
- 一键导出到手机 Files/Documents，包含 JSON、摘要.txt、SHA-256 清单；
- 用系统分享/数据线/U 盘交给警方或家属，不经过云端；
- 电脑与手机局域网二维码配对，只做本地只读/导出，不建服务器副本；
- 应用锁/生物识别、导出二次确认、锁屏不显示敏感内容、默认不自动云备份。

归属层：B10 移动端 + B1 数据生命周期 + B2 身份 + B3 隐私。详见 [LAYER-MAP.md](LAYER-MAP.md)。

## 9. 设计原则

- **接住人优先**：保存失败不能影响危机回应；
- **数据主权**：记录属于用户，不属于产品；
- **最小化**：只保留问题、时间、地区；
- **可核验**：SHA-256 清单让「没有被改过」可以被检查；
- **不自动共享**：真相可以交给该交的人，但不由产品替用户决定；
- **不二次伤害**：导出说明明确提醒，不要把它变成对当事人的指责材料。
