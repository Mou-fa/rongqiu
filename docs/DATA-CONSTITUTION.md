## 0. 三行宪法

> **对政府：无用。**
> **对用户：无险。**
> **对科学（聚合之后）：有用。**

这三件事必须同时成立。少一条，绒球就没有资格谈全球化。

---

## 1. 两个词的定义

**内容（Content）——永远不留、不外发：**

- 用户输入的自然语言原文；
- 语音音频、声纹、环境声音；
- 导入的聊天记录、截图、图片、日历、邮件；
- 判断依据的原文；
- 任何能还原上述内容的摘要、嵌入向量、日志、缓存、崩溃报告。

**形状（Form）——唯一允许长期存在的东西：**

- 是 / 否的回答；
- 问句 id、顺序（自适应路径）；
- 结构计数（N、方向、置信度、粗分类、模糊时间）；
- 聚合后的统计量与校准结果。

**留形状，不留内容。**

---

## 2. 数据分层与生命周期

| 数据 | 存在哪 | 活多久 | 谁能拿到 |
|---|---|---|---|
| 输入原文 | 设备内存 | 当下（生成形状后即丢弃） | 只有用户 |
| 语音音频 | 设备内存 | 转录完成即丢弃 | 只有用户 |
| 导入材料 | 设备内存 | 提取出形状后即丢弃 | 只有用户 |
| 判断结构（N / 681 / 半知） | 本机判断日志 | 用户自己决定；可一键删除 | 只有用户 |
| 个人「是 / 否」路径 | 本机 | 同上 | 只有用户 |
| 校准结果（个人曲线） | 本机 | 同上 | 只有用户 |
| 聚合统计（去标识） | 区域聚合层 | 长期 | 公开（DP 后） |
| 问句库 / 代码 / 算法 | 公开仓库（AGPL） | 永久 | 所有人 |
| 环境讯息（时间 / 地点 / 天气） | 只展示，不落盘 | 当次会话 | 不进入任何面 |
| 账号 / 支付 / IP / 日志 | 最小化；最好没有 | 最短 | 现状风险点，见 §7 |

**原则：能在设备上完成的，绝不上服务器；能当下完成的，绝不落盘；能聚合的，绝不留个体。**

## 3. 数据库：只存「是 / 否 的不规则排序」

### 3.1 它是什么

问句库是**字母表**，一次判断是一条**自适应二元码**；「不规则排序」不是乱序——它是**提问顺序的路径**，顺序本身携带信息。

服务端（如果存在聚合层）只存：

| 表 | 内容 | 粒度 |
|---|---|---|
| 问句边缘统计 | 每句问句的是 / 否计数 | 按问句 |
| 路径前缀计数 | 某个前缀下的是 / 否计数 | 按前缀，不按用户 |
| 结果条件统计 | 答了是 / 否之后实际发生的比例 | 按问句 × 粗分类 |
| 校准格 | 置信度 × 命中率 | 必须踩 k-匿名与 DP 门槛 |
| 信息增益 | 每句问句降低的熵 | 按问句 × 粗分类 |

**绝不存：** 用户 id ↔ 路径的映射、完整个人路径、原文、音频、内容嵌入。

### 3.2 及时性

- 判断生成 → 当次转成形状 → 内容丢弃 → 聚合层只收形状；
- 结果回收（默认 3 天）→ 当次更新聚合 → 不囤历史原文；
- **不存内容，就没有「以后被翻出来」的那颗定时炸弹。**

### 3.3 代价：不可回溯

不存原始数据，意味着未来出现的新问题没法回头重算。
**所以什么算「充分统计量」，是一份宪法级决策**：留哪些计数、哪些桶、哪些前缀，必须现在想清楚；任何 schema 变更走 §9 的程序。

### 3.4 聚合的硬门槛

- **k-匿名**：任何对外统计的最小格子不小于 k（初始 k = 50，只允许调大）；
- **差分隐私**：发布值与加入噪声后的值不可区分；
- **小格抑制**：样本不足的格子直接不发布，不合并、不四舍五入到能被反推；
- **不链接**：聚合层不做用户级 join，不做跨表身份拼接。

## 4. 技术不变量（代码里必须为真）

1. **没有任何服务端接口接收内容**（原文 / 音频 / 图片 / 导入材料）。
2. 内容不进入日志、崩溃报告、分析、队列、备份。
3. 没有能读取内容的第三方 SDK；所有对外请求列在 [PRIVACY.md](PRIVACY.md)，可审计。
4. 本地数据用户可删、可导出、可离线运行；删了就真的没了。
5. 聚合必须 DP + k-匿名；小格不发布。
6. 无账号也能用；支付不关联判断内容。
7. **不存在「远程打开内容收集」的开关**：想加这个能力，必须改开源代码、人可见。
8. **网络审计**：抓一次完整使用流程的全部请求，里面不能出现用户原文。
9. **语音**：本地 ASR；音频不落盘；只保留用户确认后的状态比特。
10. **模型**：内容不用于训练中心模型；若做联邦 / 安全聚合，只出梯度或形状统计，且可审计。

## 5. 司法 / 政府请求协议

**收到请求，先分类，再回答。**

| 请求类型 | 我们的回答 |
|---|---|
| 要内容（原文 / 音频 / 导入材料） | **不存在，无法提供。** 附公开的网络审计与架构说明 |
| 要用户级数据（路径 / 校准） | **服务器上不存在。** 个人数据只在用户设备 |
| 要聚合统计 | 可以给——它本来就是公开的 DP 统计 |
| 要「能力」（后门 / 强制记录 / 改代码） | **拒绝。** 宁可退出该市场，也不改架构 |

**流程：** 法律审查 → 分类 → 回复 → 记录 → 季度透明度报告。
**红线：** 不静默配合、不建后门、不隐瞒请求；法律允许时通知用户；设 warrant canary。

**一句话回复模板：**

> 我们不具备此类数据。可提供的是：公开的代码、公开的问句库、以及去标识的聚合统计。

## 6. 全球化模型

| 层 | 通用 | 本地化 |
|---|---|---|
| 结构（N11 / 811 / 半知 / 翻转） | ✅ 全球同一套 | — |
| 问句库 | 结构通用 | **词汇、语境、文化本地化**（护城河） |
| 数据 | **无内容** | 区域聚合；数据本地化法规「无可本地化之物」 |
| 部署 | 本地优先 | 各市场合规审查；要内容/后门 → 退出 |

**跨境只允许两种东西：** DP 聚合统计，或者什么都不传。

## 7. 现状 vs 宪法（必须承认的欠账）

| 数据流 | 现状 | 宪法要求 | 状态 |
|---|---|---|---|
| LLM 解析 / 判向 | 问题原文发给模型服务（PRIVACY 已列） | 本地模型，内容不出设备 | **欠账** |
| 搜索 | 派生检索词发给搜索服务 | 本地语料 / 用户知情可选 / 删除该层 | **欠账** |
| 语音 | 未接入 | 本地 ASR，音频不落盘 | 未开始 |
| 判断日志 | 本机 data/ | 符合（本机 + 可删） | ✅ |
| 聚合层 | 不存在 | DP + k-匿名 | 未开始 |

**发布前检查：内容类外发必须清零；清不掉，就不发布、不全球化。**

## 8. 反模式（出现即违宪）

- 账号体系绑定判断内容；
- 云端同步原文 / 音频 / 截图；
- 分析 SDK、崩溃上报带原文；
- 用用户判断训练中心模型；
- 广告、推荐、画像、按情绪组织内容；
- 卖「脱敏」数据；
- 给政府留后门或静默配合；
- 用「匿名」二元序列做用户级追踪；
- 发布小格统计、能被反推的聚合；
- 语音上云；情绪推断进事实层（见 [VOICE.md](VOICE.md)）。

## 9. 变更程序与发布前检查

**这份文件的修改，和红线一样走 [REDLINES.md](REDLINES.md) 第六部分：**
提出 → 公开 → 30 天冷静期 → 复核 → 永久记录。

**任何新增数据收集，先回答五问：**

1. 它含内容吗？含，直接否。
2. 它必需吗？不必需，删。
3. 它最小吗？能粗化就粗化。
4. 它聚合了吗？个体级数据不出设备。
5. 用户能删 / 能拒吗？不能，否。

**发布检查：** 网络审计（无原文）· 存储审计（无音频 / 无内容日志）· 聚合审计（k / DP / 小格）· 透明度报告（请求数 / 可提供数 = 0）。
