## 为什么是蒲公英

最初的灵感就是蒲公英。中间绕了远路——试过五版「毛球 + 旋」，
其中一版被指出像病毒。

病毒感的根源不是配色，是结构：**圆形实心体 + 四周放射状的刺**。
只要这个结构在，画的是毛、是刺、是光，读起来都是病毒。

蒲公英不会像病毒，因为它有三样病毒永远没有的东西：

| | 病毒 | 蒲公英 |
|---|---|---|
| 中心 | 实心球 | **空的** |
| 线端 | 疙瘩 | **一撮小伞（冠毛）** |
| 命运 | 不动 | **种子会飞走** |

而飞走这件事正好承载了理论：

> **球上有一个缺口，一颗种子已经飞走了。**
> **那颗飞走的，就是 811 里那 20% 永远抓不到的未知。**
> **留下来的每一根，才是你能数的第一接触面。**

## 文件

| 文件 | 用途 |
|---|---|
| `icon.svg` | 母版 |
| `icon-{512,256,128,64,32,16}.png` | 各尺寸 |
| `favicon.ico` | 16/32/48 三档 |
| `../app/static/icon.svg` | 应用内头部 logo |
| `../app/static/favicon.ico` | 浏览器标签页 |

黑底黄线是实心的，缩到 16px 仍然可辨，所以不需要另做简化版。

## 重新生成

```bash
python scripts/make_icon_svg.py            # → docs/icon.svg
python scripts/make_icon_preview.py icon.svg
# 用 Edge 把 docs/_preview_icon.html 截成 512px → docs/icon-512.png
python scripts/make_icon.py                # 全套尺寸 + favicon
```
