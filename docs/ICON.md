# 绒球图标

![icon](icon-512.png)

## 从蒲公英来，但不止于蒲公英

最初的灵感是蒲公英——一团会散开的绒毛。但「画一朵蒲公英」谁都能画，
它不承载绒球的理论。所以图标里多做了一件事：

> **把那撮梳不平的旋画进去。**

毛球定理说：你没法把一个球上的毛全部梳平，任何梳法都至少有一个旋。
这正好是 811 里那 20% 永远拿不到的未知——不是数据不够，是拓扑上不允许。

所以图标是：**一团毛茸茸的球，一处毛自己卷成了旋。**

| 元素 | 含义 |
|---|---|
| 柔粉实心球 | 绒球本身——你要摸的那个东西 |
| 边缘两圈短毛 | 第一接触面，向外发散 |
| 右上角的绿色螺旋 | 毛球定理的旋 = 那 20% 的盲区 |
| 中心一点绿 | 原核 |

## 为什么是「实心球 + 边缘绒」

前三版都画成了「从圆心向外的辐条」，结果：

- 第一版：像太阳
- 第二版：像海胆
- 第三版：像长了毛的球，但 32px 下糊成一团

**辐条的问题是没有形体**——缩到 16px 就散了。
实心球缩小后仍然是一颗球，毛只负责边缘的蓬松感。

## 颜色

粉色是绒球的颜色，绿色是 UI 的主色（`--accent: #3f6b4f`）。
**粉色球 + 一点绿**，正好对应界面里「绒球渐变 + 绿点」的视觉语言。

## 文件

| 文件 | 用途 |
|---|---|
| `icon.svg` | 母版，矢量，任意缩放 |
| `icon-512/256/128/64/32/16.png` | 各尺寸位图 |
| `favicon.ico` | 16/32/48 三档，浏览器自己挑 |
| `../app/static/icon.svg` | 应用内使用（头部 logo） |
| `../app/static/favicon.ico` | 浏览器标签页 |

## 重新生成

```bash
python scripts/make_icon_svg.py      # 生成 docs/icon.svg
python scripts/make_icon_preview.py  # 生成渲染用包装页
# 用 Edge 把 docs/_icon_preview.html 截成 docs/icon-512.png
python scripts/make_icon.py          # 生成全套尺寸和 favicon
```

颜色、密度、旋的位置都在 `scripts/make_icon_svg.py` 顶部几个常量里。
