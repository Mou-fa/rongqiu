# 绒球图标

![icon](icon-512.png)

## 从蒲公英来，但避开了病毒

最初的灵感是蒲公英。但图标改到第五版才成立。

**前四版全部被否掉，原因是同一个：**

> 圆形实心体 + 四周放射状的刺 = 教科书级的病毒画法。

这不是配色问题，是**结构问题**。只要「从圆心向外伸出的线」还在，
无论画的是毛、是刺、是光，读起来都是病毒。

第五版把这条结构彻底拿掉：**没有任何从圆心向外的长线**。
改用一千五百根**随机方向**的极短绒，铺满球体——
因为方向是随机的，就永远不会形成放射状的刺。

## 它画的是什么

| 元素 | 含义 |
|---|---|
| 柔粉绒球 | 绒球本身——你要摸的那个东西 |
| 铺满球体的短绒 | 第一接触面。随机方向，所以没有「朝外」的特权方向 |
| 右上角的绿色螺旋 | 毛球定理的旋 = 811 里那 20% 永远拿不到的未知 |
| 中心一点绿 | 原核 |

毛球定理说：你没法把一个球上的毛全部梳平，任何梳法都至少有一个旋。
这正好是那 20%——不是数据不够，是拓扑上不允许。

**所以这个图标里，绒是随机长的，只有一处被梳成了旋。**

## 迭代记录

| 版本 | 画法 | 被否原因 |
|---|---|---|
| v1 | 圆心向外的辐条 | 像太阳 |
| v2 | 三层长短不一的发散毛 | 像海胆 |
| v3 | 加大密度 | 圆了，但 32px 下糊成一团 |
| v4 | 实心球 + 边缘绒毛 | 形体对了，但**像病毒** |
| **v5** | **实心球 + 随机方向短绒 + 螺旋** | ✅ |

## 颜色

粉色是绒球的颜色，绿色是 UI 主色（`--accent: #3f6b4f`）。
**粉绒球 + 一点绿**，对应界面里「绒球渐变 + 绿点」的视觉语言。

## 文件

| 文件 | 用途 |
|---|---|
| `icon.svg` | 母版，矢量 |
| `icon-512/256/128/64/32/16.png` | 各尺寸位图 |
| `favicon.ico` | 16/32/48 三档 |
| `../app/static/icon.svg` | 应用内头部 logo |
| `../app/static/favicon.ico` | 浏览器标签页 |

## 重新生成

```bash
python scripts/make_icon_svg.py      # 生成 docs/icon.svg
python scripts/make_icon_preview.py  # 生成渲染用包装页
# 用 Edge 把 docs/_icon_preview.html 截成 docs/icon-512.png
python scripts/make_icon.py          # 生成全套尺寸和 favicon
```

颜色、绒的密度、旋的位置都在 `scripts/make_icon_svg.py` 顶部常量里。
