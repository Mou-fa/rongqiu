# 绒球图标

![icon](icon-512.png)

## 就是这张图

用户提供的原图（黄底黑线手绘蒲公英），只做了三件事，**没有重新设计**：

1. **黄黑对调** —— 黄底黑线 → 黑底黄线
2. **裁到内容包围盒** —— 去掉原图四周的空白和边框
3. **放大撑满** —— 只留 3.5% 边距

## 处理方式

原图是纯黄 `(255,255,0)` 底 + 纯黑 `(0,0,0)` 线。
对调不是简单取反，而是**按亮度反推线条的透明度**，这样抗锯齿边缘也能保住：

```
亮度 > 150  → 纯背景 → 黑色
亮度 < 85   → 纯线条 → 黄色
中间        → 线性过渡（抗锯齿）
```

第一版拿「最大亮度」当归一化基准，结果背景成了暗橄榄色——
**统计量会被压缩噪声带偏，固定阈值才可靠。**

## 这一版之前绕的远路

中间试过六版自己画的「毛球 + 旋」，其中一版被指出**像病毒**。
病毒感的根源是结构性的：**圆形实心体 + 四周放射状的刺**。
只要这个结构在，画的是毛、是刺、是光，读起来都是病毒。

最后回到最初的那张图。
