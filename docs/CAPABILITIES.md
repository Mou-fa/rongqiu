## 怎么读这份文件

**每一项能力只写四件事：**

1. **它回答什么** —— 用户能问出的一句话
2. **怎么算** —— 判据（不是形容词，是可复现的规则）
3. **什么时候不说话** —— 边界。沉默是设计的一部分
4. **为什么不算引导** —— 它和红线的关系

**没写清楚「什么时候不说话」的能力，不算能力。**

# 二、核心链路

## 1. 原核解析

**它回答什么**

> 「我这句话，到底在问什么？」

**怎么算**

把问题拆成 **代理 · 事件 · 资源**，剥掉时间、地点、修饰语。

```
「今晚身体不舒服，能不能去聚餐？」
  → 原核  我 · 参加 · 聚餐
  → 自述  我 · 身体不舒服 · 身体        （顺带说出的处境）
```

**为什么要规范化**

「今晚的聚会我该去吗」和「今晚聚会要去吗」必须解析成同一条三元组。
**同一个问题不能因为换了个说法就变成另一个原核。**

**边界**

- 某一格填不出 → 留空，并要求用户补充
- 多重动作 → 只保留最核心的那一个

---

## 2. 第一接触面检索

**它回答什么**

> 「和这件事直接接触的，是什么？」

**怎么算**

在全网找**同主谓宾结构**的文本，浓缩成一句，给用户看。

**关键：这些不是证据，是镜子。** 用户认领了才算事实。

**边界**

- 只找直接因、直接果、共同原因（马尔可夫毯）
- 隔着两跳以上的不算第一接触面
- 找不到就空着，不硬凑

---

## 3. 二元判向

**它回答什么**

> 「这条事实，对这一件事，是支持还是反对？」

**怎么算**

模型判，三次投票 + 强制二元。判成中性的会被逼着选一边。

**判据不是「想不想做」，是「会不会做」。**

> 「我最近很累」对「去聚餐」→ **反对**（不是因为不想，是因为去不了）

**边界**

- 用户认领的事实**不允许弃权**——你点了「这是我的情况」，它就不可能对决定没有方向
- 主动询问的答案方向由**用户点击直接决定**，不经过模型

---

## 4. 811 结构计算

**它回答什么**

> 「这个判断有多确定？」

**怎么算**

```
可确定 = min(N / (N + 2), 0.8) × 0.8^(链长 - 1)
剩余 = 1 - 可确定，按 1:1 分给半知和未知
```

**N 再多也超不过 80%。**

**边界**

- 三段相加永远严格等于 1
- N < 8 时可确定更小
- 链长 > 3 自动降为「暂定判定」

---

## 5. 固定询问面

**它回答什么**

> 「还有哪些角度可以看这件事？」

**怎么算**

问句来自 `configs/questions.yaml`，**由人写好，系统不发明。**

每个问句带极性（答是 → 支持 / 反对）、理由、适用场景。

**问行为不问动机：**

> **你上一次遇到这种情况，最后怎么选的？**

**边界**

- 点选是补充，不是必经之路
- 用户什么都不答，系统也能只靠自述给结构

---

## 6. 环境讯息

**它回答什么**

> 「此刻你所在的世界是什么样的？」

**怎么算**

时间（本地）、地点（反查）、天气（Open-Meteo）。

**只展示，不计入任何面。**

**为什么**

> **环境是场，不是面。**
> 它影响判断，但它不属于「你这个人身上的东西」。

**边界**

- 只收裸数据（温度 13°C），不收加工过的结论（「今天适合外出」）
- 不做个性化

---

## 7. 判断归档

**它回答什么**

> 「我上次是怎么想的？」

**怎么算**

每次判断记一条，只增不改不删。回收期跟着问题的时间尺度走（默认 3 天，2026-10-20 从 7 天缩短）：

| 问题里的时间词 | 回收期 |
|---|---|
| 今晚 / 今天 / 明天 | 1 天 |
| 没有时间词（默认） | 3 天 |
| 这周 / 周末 | 7 天 |
| 这个月 / 今年 | 30 天 |

---

## 8. 校准统计

**它回答什么**

> 「我说的和实际发生的，差多少？」

**怎么算**

- **Brier 分数**：预测概率与结果的平均平方误差
- **可靠性曲线**：按预测值分箱，比较预测均值与实际频率
- **校准偏差**：命中率 − 平均置信度（负数 = 高估）

**边界**

- 没有回收数据就不出统计
- 样本少时不出结论

# 三、潜藏能力（本次新增的四项）

## 9. 跨决定共同根因

**它回答什么**

> 「我这几个问题，是不是其实是同一个？」

**怎么算**

1. 取每条判断里**用户自己说出的面**（排除通用问句）
2. 两两比较，判断是不是同一个面
3. 同一个面出现在**至少 2 个不同的问题**里 → 成组

**比对面用的判据：三段式**

```
主语必须一致 + 宾语必须一致 + 谓语相近
```

**为什么不用整串相似度**

- 靠字符重合会漏：「最近很累」vs「很累」
- 整串相等会误判：「最近很累」vs「最近很开心」（宾语一样、谓语相反）

三段式正好把两个毛病都挡掉。

**什么时候不说话**

- **同一个问题问了十遍不算**——那是反复纠结，不是跨决定
- 少于 2 个不同的问题 → 不成组
- 通用问句（主动询问）不参与判定：它在每个决定里都一样，是问卷不是根因

**为什么不算引导**

> 输出是「这三个决定共享同一个面」，不是「所以你应该先解决累的问题」。

**已知局限**

字面匹配不是语义匹配。「最近很累」和「比较累」认不出来。
**不上语义匹配的理由：** 同一个抽取管线对同一个事实写法稳定，字面匹配覆盖绝大多数；真上 LLM 比对比对成本高且有稳定性风险。

---

## 10. 决策拓扑排序

**它回答什么**

> 「这些决定之间，谁影响谁？」

**怎么算**

> **A 的原核资源（或事件）出现在 B 的用户自述面里 → A 影响 B。**

只看向 B 说了什么，不看 A 说了什么。

**为什么只看 B 的面**

如果连问题文本一起看，「我要不要搬家」自己就会和「搬家」这个资源自连。

**什么时候不说话**

- 没有边就是没有边，宁可空着不硬连
- 一个字的词不当作依赖信号
- **互相依赖的两个决定，单独列出来，不假装能排成一条链**

**性能设计**

原核解析是 LLM 调用。但日志里同一个问题会被问很多遍——
先按问题去重，再逐条解析，结果写进 `data/nucleus_cache.json`。

```
204 条记录 → 去重后 21 个不同问题 → 只解析 21 次
第一次 26.8 秒，之后零成本
```

**为什么不算引导**

输出是「A 影响 B」，不是「所以先做 A」。
**排序是结构，指示才是引导。**

---

## 11. 判断漂移

**它回答什么**

> 「同一个决定，隔了一段时间再判，什么变了？是事实变了，还是我变了？」

**怎么算**

取同一个问题的最早一次和最近一次，比较：

| 类别 | 判据 | 含义 |
|---|---|---|
| **facts** | 事实集合变了（新增/消失） | 该更新判断 |
| **self** | 事实没变，但结论翻转或置信度变化 > 10% | 情绪在替你判 |
| **none** | 没变化 | 不输出 |

**什么时候不说话**

- **两次判断间隔小于 12 小时，不算**
- 事实和结论都没变，不输出

**为什么有 12 小时这条线**

> 一小时内问五遍，不叫漂移，叫反复纠结。

**为什么不算引导**

> 「两次判断没有哪个更对。这里只记录差异。」

**不推测原因**——只说「变了什么」，不说「为什么变」。

---

## 12. 校准缺口预警

**它回答什么**

> 「这次你说 85%。但你在这一类上，历史命中是多少？」

**怎么算**

1. 按关键词把决定分成 工作 / 社交 / 消费 / 健康 / 学习 / 其他
2. 统计每一类的已回收记录：平均置信度 vs 实际命中率
3. **缺口 = 命中率 − 平均置信度**（负数 = 高估）
4. 当前判断的置信度落入该类别 → 预警

**什么时候不说话（三条）**

- **样本不够不说**：少于 5 条已回收记录，沉默
- **缺口小不说**：±10% 以内视为校准良好
- **没有回收数据不说**：整块不出现

**为什么不算引导**

> 它说的是「你以前是什么样」，不是「你这次该怎样」。

**这是唯一一种「用数据帮用户」又不算引导的方式。**

# 四、安全能力

## 13. 安全例外

**它回答什么**

> （不回答任何问题。）

**它做什么**

**当用户表达自伤、自杀、绝望、轻生的意图时，绒球立即停止工作。**

结构、倾向、置信度——**全部不出**。
只做一件事：把求助渠道递给他。

**为什么它高于一切红线**

> 一个已经不打算继续活着的人，不需要结构。
> 这时候给结构，是残忍。

**怎么算**

纯确定性关键词匹配，**不调用任何模型**——因为这条路径不能在故障时失灵。

**触发范围**

直接表达 / 计划 / 告别 / 绝望 / 自伤 / 方式，共 9 类。

**良性用法排除**

「想死你了」「笑死」「累死」「社死」

**原则**

> **宁误报，不漏报。**
> 误报的代价是一次尴尬；漏报的代价是一条命。

**严格禁止**

不写「你要坚强」、不写「我理解你」、不做诊断、不给建议、不追问为什么、**绝不给结构**。

**发布门槛**

> 危机用例不全绿，其他全过也不许发布。

# 七、一条总原则

**看完这 13 项能力，会发现它们遵守同一件事：**

> **每一项能力都写清了「什么时候不说话」。**

**因为绒球最核心的能力不是「算得准」，是「知道什么时候不该算」。**

```
N 再多也超不过 80%
样本不足就沉默
缺口小就不说
没有边就不连线
危机就不给结构
```

**——这五行是同一条原则的五种写法。**

**它不是谦虚，是设计。**
